# Baguette & Bureau - Landing Page

Landing page pour le projet Baguette & Bureau, la solution d'automatisation des commandes B2B pour les boulangeries.

## Technologies

- **Next.js 15** - Framework React
- **TypeScript** - Typage statique
- **Tailwind CSS** - Framework CSS utility-first
- **Lucide React** - Icônes modernes

## Installation

```bash
npm install
```

## Développement

```bash
npm run dev
```

Ouvrir [http://localhost:3000](http://localhost:3000) dans votre navigateur.

## Build Production

```bash
npm run build
npm start
```

## Structure du projet

```
/app
  /page.tsx        # Landing page principale
  /layout.tsx      # Layout racine
  /globals.css     # Styles globaux
```

## Sections de la landing page

1. **Hero** - Titre accrocheur et CTA principal
2. **Problème** - Les douleurs des boulangers (50 interruptions/jour)
3. **Solution** - Comment Baguette & Bureau automatise tout
4. **Bénéfices** - Gains de temps concrets (3h/jour)
5. **Comment ça marche** - 4 étapes simples
6. **Fonctionnalités** - Toutes les features clés
7. **Témoignage** - Social proof
8. **CTA Final** - Appel à l'action principal

## Déploiement

Le projet peut être déployé sur Vercel, Netlify ou tout autre plateforme supportant Next.js.
